# media-inheritance-polymorphism
A Python OOP project demonstrating inheritance, polymorphism, method overriding, and the super() function through Book, Magazine, and DVD subclasses.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP)
2. Classes and Objects
3. Inheritance
4. Polymorphism
5. Method Overriding
6. Constructor (__init__)
7. super() Function
8. Parent and Child Classes
9. Instance Attributes
10. NotImplementedError
